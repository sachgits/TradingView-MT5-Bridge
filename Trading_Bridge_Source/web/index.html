      Runtime settings

      Changes take effect immediately and survive a restart. All fields are applied together: if one is invalid, none of them change.

      Intake

      The inbox is shared with other producers and is read-only: the bridge lists and reads it, never renames, marks or deletes anything there. Every file it consumes is copied into its own data folder, and the copy carries the outcome. What has already been consumed is remembered in the ledger, not in the inbox. You can point it at a different folder above without restarting; whatever is already in the new folder is adopted and will not be traded.

      Fixed at startup

      These need a restart because they rebind sockets or move the ledger. Set them with TRADING_BRIDGE_* environment variables or command-line flags.
